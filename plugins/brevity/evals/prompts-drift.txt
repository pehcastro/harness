# at position 0, and its influence falls as the conversation grows. A real
# 424-reply session showed mean reply length rising 63, 74, 63, 87, 95 across
# its fifths, with banned status words rising 3 to 11. A 28-turn run of this
# same app stayed flat at 93, 96, 99, so it could not test the thing.
#
# This suite keeps working on one app long enough for the distance between the
# system prompt and the current turn to matter. Turns are ordinary product work,
# not tests of any single rule, because drift is about accumulation rather than
# any one hard case.
#
# Delegation is spread across the session (13, 27, 41, 55, 68) rather than
# clustered, so an agent report lands in every fifth and length can be compared
# like for like.
